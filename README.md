# あいうえバトル オンライン

幻冬舎エデュケーション『もじあてゲーム あいうえバトル』（米光一成デザイン）の友人内対戦用Web実装。

## 概要

- 2〜5人プレイ対応
- PeerJSによるP2P通信、ホスト=審判モデル
- 単一HTMLファイル、GitHub Pagesでそのまま動く
- 4文字Room IDで参加（LINE等でID共有）
- 50音 / アルファベット 切替対応
- ホストが自由にお題入力 or リストからランダム選出

## 遊ぶまでの流れ

1. ホストが`aiue_battle_online.html`を開いて「部屋を作る」をタップ
2. 4文字のRoom IDが表示されるので、参加者にLINE等で共有
3. 参加者は同じURLを開いて「部屋に参加する」、Room IDを入力
4. 全員揃ったらホストが「ゲーム開始」
5. ホストがお題を決定 → 全員が言葉を入力 → 50音バトル開始
6. 最後まで残った人が勝ち。新ラウンドはホストの「新しいラウンドを始める」から

## GitHub Pagesにデプロイする手順

### 1. リポジトリを作る

GitHubで新規リポジトリを作成（publicでOK）。例: `aiue-battle-online`

### 2. ファイルをアップロード

リポジトリ内に`docs`フォルダを作り、その中に`aiue_battle_online.html`をアップロード。`README.md`はリポジトリのルートに置く。

### 3. GitHub Pagesを有効化

リポジトリの`Settings` → `Pages`を開く。

- **Source**: `Deploy from a branch`
- **Branch**: `main` / **`/docs`**
- `Save`をクリック

数分後、`https://<ユーザー名>.github.io/aiue-battle-online/aiue_battle_online.html` のURLが発行される。

### 4. URLを共有

このURLを友達に共有すれば全員ブラウザで開ける。Room IDは毎回ランダム生成なので、URLは公開でも問題なし（IDを知らない人はゲームに参加できない）。

## 技術仕様

- **通信**: PeerJSの公開シグナリングサーバー経由でP2P接続
- **アーキテクチャ**: ホスト=審判モデル。ホストが authoritative な状態を持ち、各クライアントには「自分の言葉＋公開済み情報のみ」をフィルタ送信
- **依存**: PeerJS 1.5.4（CDN）、Google Fonts（RocknRoll One / Zen Maru Gothic / Klee One）

## ルール実装メモ

公式ルールに準拠：

- 各プレイヤー7枚のちょっかんくん。2〜7文字の言葉を入力、空きには×が自動補完
- 濁点・半濁点・小文字は入力時に自動清音化（ぱんだ→はんた、しゃけ→しやけ）
- 連続攻撃は最大2回（成功で続行、失敗 or 2回目で手番終了）
- 自爆あり（自分の使っている文字を攻撃したら自分のカードも公開、連続攻撃の権利は維持）
- 同じ文字が複数ある場合は全部公開
- ×以外の全カードが公開されたプレイヤーは脱落
- 同時脱落時は最後の攻撃者が勝利（引き分けなし）

## 既知の制約

- PeerJSの公開シグナリングサーバー依存（無料利用、稀に不安定）
- 対称NAT環境では繋がらない可能性（その場合TURN必要、別途設定）
- ホストが切断するとゲーム終了
- 文字判定はホスト側authoritative、クライアントの不正は基本起きない設計
